## Co je nového

- **Telefon**: všechny dialogy se vejdou na displej. Elektronická podání
  mají na telefonu seznam služeb a formulář zvlášť, údaje se ukazují
  s popiskem nad hodnotou.
- **Kdo zprávu odeslal** ukazuje čitelně roli, jméno a další údaje místo
  technické odpovědi ISDS. Totéž platí pro informace o schránce
  a uživateli.
- **Doručenka a události**: čas je nad textem události, takže se dobře čte
  i na telefonu.

## Instalace

Na Macu, Linuxu a Windows se tato verze nainstaluje sama: aplikace ji při
startu nabídne. Ručně ji stáhnete z tabulky níže.

| Systém | Soubor |
|---|---|
| macOS 12 a novější | `DatovkaNG-macos.zip` |
| Ubuntu, Debian, Mint | `DatovkaNG-linux-amd64.deb` |
| Linux na ARM | `DatovkaNG-linux-arm64.deb` |
| Windows 10 a 11 | `DatovkaNG-windows-amd64.zip` |
| Android 7 a novější | `DatovkaNG-android.apk` (instaluje se přes předchozí verzi) |
